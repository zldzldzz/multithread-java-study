## Section 07 - 동기화

이 장은 여러 스레드가 공유 자원에 접근할 때 발생하는  
동시성 문제에 대해 정리하고, 이 문제를 해결하는  
synchronized에 대해 정리합니다.  

### 동시성 문제
동시성 문제는 여러 개의 스레드가 같은 공유 자원을 읽을 때 값의 불일치에 대한 문제입니다.  
원인은 여러 개의 스레드가 공유 자원을 여러 개의 단계로 나누어서 사용하기 때문입니다.

예를 들어 단계 1과 2가 있고, 스레드 A와 B가 있을 때,  
스레드 A가 1에서 공유자원을 변경했는데 이것이 그래도 반영되지 않고 그냥 단계 2로 넘어가고, 
스레드 B는 A가 1을 완료한 후에 공유자원에 접근했는데 작업 내용이 반영되지 않아서 값의 불일치 문제가 발생했습니다.

이 문제를 해결하기 위해서는 공유 자원을 사용하는 과정에 있어서 스레드를 순서대로 쓸 수 있게 해서 불일치 문제를 없애는 것입니다.  

이를 위한 해결 방안이 임계 영역입니다.  
임계 영역에서는 하나의 스레드만이 들어올 수 있어서  
한 번의 작업만을 할 수 있어서 값의 불일치 문제가 발생하지 않습니다.  

자바에서는 이를 Synchronized 키워드로 사용하고 있습니다.  

### Synchronized 키워드
자바에서는 공유 자원을 사용하는 메서드에 Synchronized 키워드를 넣으면 임계 영역이 만들어져서 하나의 스레드만이 접근할 수 있습니다.  

작동 방식에 대해 정리해보겠습니다.  
자바에는 모든 인스턴스 내부에 보이지 않는 모니터 락을 가지고 있고,  
synchronized 키워드가 붙은 메서드나 코드 블록에 진입하려면, 스레드는 반드시 해당 인스턴스의 락을 획득해야 합니다.

만약 다른 스레드가 이미 락을 가지고 있다면, 새로 진입하려는 스레드는 BLOCKED 상태가 되어 대기하고,  
BLOCKED 상태의 스레드는 CPU 실행 스케줄링에서 제외됩니다.

메서드 실행이 끝나면 락을 반납하고, 대기 중이던 스레드 중 하나가 락을 획득하게 됩니다.
