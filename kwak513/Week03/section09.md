## 섹션 9. 생산자 소비자 문제 1

### 생산자 소비자 문제 = 한정된 버퍼 문제
1.  **뜻**: 여러 스레드가 특정 자원을 함께 생산하고 소비하면서 발생하는 문제
2.  **원인**: 한정된 버퍼 크기
3. **해결**: 큐에 데이터가 가득 차있어도, 공간이 없어도 대기 가능 (버리는 데이터 X)
   - 반복문 + sleep()을 통해, 특정 조건 만족 시까지 대기
   - wait(), notify()
---
### synchronized 내부 sleep()의 문제점
1. 락을 가진 상태로 대기
---
### Object 클래스의 wait(), notify()
1. 메서드:
   - **Object.wait()**: 락을 반납하고 대기
   - **Object.notify()**: 대기 중인 스레드 중 임의의 하나를 꺠움
   - **Object.notifyAll()**: 대기 중인 모든 스레드를 깨움
2. 한계:
   - 비효율: 스레드 대기 집합 1개 -> 생산자가 생산자를, 소비자가 소비자를 깨울 수도 있음
   - 스레드 기아 현상: 대기 큐의 스레드가 순차적 실행 X
