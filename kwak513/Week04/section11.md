## 섹션 11. CAS - 동기화와 원자적 연산

### 원자적 연산
1.  **뜻**: 더 이상 나눌 수 없는 단위의 연산
2.  **멀티스레드 상황에서 문제 발생 유무**: X
3. **예시**: i++은 원자적 연산일까? X
   - i++은 i = i + 1과 같고,
   - 오른쪽 i의 값을 읽고
   - 1를 더하고
   - 왼쪽 i에 대입하는 순서로 나뉘기 때문에 원자적 연산이 아님.

### 락 방식의 문제점
1.  락을 획득하고 반납하는 과정의 반복
    - 스레드의 상태가 RUNNABLE, BLOCKED, WAITING으로 전환

---
### CAS
1.  **약어**: Compare And Set
2. **특징**: **락 프리 기법**
   - 락 사용하지 않고, 모든 스레드가 동시에 실행되고, 충돌이 발생하면 재시도
3. **순서**: 
    1. AtomicInteger, AtomicLong, AtomicBoolean 등 변수 생성
   2. compareAndSet(a, b) 연산 수행
4. **예시**: 
- compareAndSet(0, 1)
   - 현재 0 이면 1로 변경
   - 원자적이지 않은 연산을, 하나로 묶어서 원자적으로 실행
5. **단점**:
    - **스핀 대기 / 바쁜 대기**: 대기 스레드도 RUNNABLE -> CPU 자원을 계속 사용
    - 스레든 간의 충돌이 빈번하면, 성능 저하
