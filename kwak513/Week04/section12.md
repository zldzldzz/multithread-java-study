## 섹션 12. 동시성 컬렉션

### 스레드 세이프
1.  **뜻**: 여러 스레드가 동시에 접근해도 괜찮은 경우
2. 컬렉션 프레임워크(ArrayList, HashMap 등) 대부분은 스레드 세이프 X
   - 이유: 내부에서 수많은 복잡한 연산이 수행되기 때문(원자적 연산 X)
   - => 멀티스레드 상황에서 일반적인 컬렉션 사용 X

---
### 프록시
1.  **역할**: 동기화(synchronized) 기능 처리
2. **순서**: synchronized 걸고, 원본 대상 호출
3. **구조**: 클라이언트 -> **프록시** -> 서버
4. **프록시 패턴**: 
   - 프록시 객체는 실제 객체에 대한 참조 유지
   - 그 객체에 접근하기 전에 추가적 처리

---
### synchronized 컬렉션
1.  **예시**: Collections.synchronizedList(new ArrayList<>());
2. **단점**: synchronized 잠금 범위 넓음

---
### 동시성 컬렉션
1.  **뜻**: 스레드 세이프 컬렉션
2. **예시**: HashMap의 대안인 ConcurrentHashMap
3. **장점**: 
- 성능 최적화 기법이 내부에서 적용됨. 
  - 동시성 컬렉션은 synchronized 컬렉션보다 락 범위를 세분화해 성능을 높임
